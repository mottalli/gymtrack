# Exercise illustrations

These 30 standalone SVG files are the **source of truth** for the artwork and
animation: one `*-side.svg` and one `*-front.svg` per exercise. Open a file
directly in a browser to see its animation; no app, stylesheet, or generator is
required.

## Editing

- Edit the SVG files directly. Geometry, colors and SMIL animation tracks are
  stored in each file, not generated by React.
- All files share a `0 0 300 220` viewBox and a four-second repeating cycle.
  Keep paired views on the same timing.
- `<animate>` changes joint positions; `<animateTransform>` moves equipment.
  `values` and `keyTimes` must contain the same number of entries.
- Keep the accessible `<title>` / `<desc>` and their `demo-title` /
  `demo-description` IDs. The app gives each inline copy unique IDs.
- Classes such as `demo-leg-0` are semantic test hooks, not external styling
  dependencies. Colors and stroke attributes are self-contained.
- Some vector editors remove SMIL tracks on save. Check that animations remain
  intact before replacing a file. Illustrations still need technique review.

`src/components/exerciseDemos.ts` contains names/cues; `exerciseSvgAssets.ts`
maps those IDs to these files. `ExerciseDemo.tsx` embeds the trusted SVG markup
inline to preserve synchronized pause/play and reduced-motion handling.

After editing, run from `frontend/`:

```sh
npm run test:exercises
```

Storybook's **ExerciseDemo → All Exercises** story is the visual gallery.
